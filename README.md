# Connect Four (Python Tkinter)

A classic Connect Four game developed using Python and Tkinter.  
This project demonstrates real-time game logic, GUI development, turn-based gameplay, and win detection.

## 🚀 Features
- Interactive Tkinter GUI
- Red and Yellow player turns
- Real-time win detection (horizontal, vertical, diagonal)
- Reset button to restart the game
- Click-to-drop mechanics for tokens

## 🛠️ Technologies Used
- Python
- Tkinter (GUI library)
- Messagebox module

## ▶️ How to Run
1. Make sure Python is installed
2. Run the Python file:

    ```bash
    python connect_four.py
    ```

3. Click on a column to drop your token
4. Alternate turns between Red and Yellow players
5. First player to connect four tokens in a row wins

## 🎮 Controls
- Click on a column with your mouse to drop your token
- Use the **Reset** button to start a new game
